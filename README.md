# CodingDoJo

## Adobe Campaign Classic v7 skill

Connects to a Campaign Classic v7 server and lists its data schemas.

- Skill: `.cursor/skills/adobe-campaign-v7/SKILL.md`
- Script: `.cursor/skills/adobe-campaign-v7/scripts/list_schemas.py`

Set `ACC_URL`, `ACC_USER`, and `ACC_PASSWORD`, then run the script. Invoke the skill in Cursor with `/adobe-campaign-v7`.
