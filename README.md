# CodingDoJo

## Adobe Campaign Classic v7 skill

Connects to a Campaign Classic v7 server and lists its data schemas, or the workflow runs that had activity in the past 24 hours and how long each run took.

- Skill: `.cursor/skills/adobe-campaign-v7/SKILL.md`
- Schemas: `.cursor/skills/adobe-campaign-v7/scripts/list_schemas.py`
- Workflow runs: `.cursor/skills/adobe-campaign-v7/scripts/list_workflow_runs.py`

Set `ACC_URL`, `ACC_USER`, and `ACC_PASSWORD`, then run the script you need. Invoke the skill in Cursor with `/adobe-campaign-v7`.
